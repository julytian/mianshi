# 微前端面试题库

> **怎么用：** 先盖住答案，按 **适用边界 → 方案对比 → 工程治理 → 故障降级** 自己口述 2～3 分钟，再点开 `参考答案` 对照补洞。追问用来模拟面试官加压；踩坑是实战里最容易翻车的点。中英文术语之间请习惯留空格，口述时也建议如此。

**编号规则：** 普通题使用 `Q1`、`Q2`……深层题使用 `D1`、`D2`……按章节目录顺序连续编号；D 题嵌入对应主题章节，不设独立「深层题」章节。

## 适合岗位 / 定位

面向 **3 年+ 前端**、**全栈偏前** 与 **前端 Lead** 候选人，默认上下文为 Vue3 管理后台与多团队协作场景。

**与相邻模块的边界：**

- [工程化](/interview/questions/03-engineering) 中的微前端相关内容**只保留组织与交付决策**（何时拆、谁发布、CI/CD 门禁怎么定），不展开四方案机制细节。
- 本模块（12）聚焦 **qiankun、Garfish、Module Federation、Wujie 四方案机制、运行时隔离与跨应用治理**，避免与 03 重复出同义题。
- [前端架构](/interview/questions/14-frontend-architecture) 回答系统如何组织与演进；[前端系统设计](/interview/questions/11-frontend-system-design) 以具体案例展开。

## 后续章节目录

1. **基础与边界** — 定义、收益与成本、拆分维度、适用与不适用场景
2. **qiankun** — 注册与生命周期、沙箱、样式隔离、通信、路由与预加载
3. **Garfish** — 加载机制、沙箱、子应用治理及与 qiankun 的差异
4. **Module Federation** — host / remote、`exposes` / `shared` / `singleton`、版本协商与部署
5. **Wujie** — Web Components + iframe 隔离、通信、保活与性能限制
6. **工程治理** — 跨应用通信、权限、监控、灰度发布与渐进迁移
7. **故障治理与架构演进** — 沙箱逃逸与路由同步、shared 版本协商、remoteEntry 降级、可观测性与四方案选型答辩
