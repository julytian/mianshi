# 面试前 3 天

> **适合场景：** 已约面，只扫速记 + 主故事 + 1 场模拟。
>
> **每日时长：** 90～150 分钟。
>
> **完成标准：** 当天主题可遮稿口述；卡点写入笔记；不新开题库通刷战线。
>
> **任务 ID 前缀：** `r3-d{n}-{slug}`（禁止复用 60 天计划 ID）。

长期能力建设仍以 [60 天完整主线](/interview/plans/60-day) 为准；本页是临场回炉，入口见 [复习总览](/interview/review/00-overview)。

### D1 — 九域速记快扫

任务 ID：`r3-d1-sheet-scan`

#### 学习目标

- 按 JD 标出加重域，速记册只扫结论卡与反例 / 红线
- 建立遮稿口述节奏，单域控制在可上场的 5 分钟量级
- 记下卡点题号，不展开通读题库

#### 材料

- [复习总览](/interview/review/00-overview)
- [框架与数据速记](/interview/review/sheets/02-framework-data)
- [工程与质量速记](/interview/review/sheets/03-engineering-quality)
- [领导力与求职速记](/interview/review/sheets/09-leadership)
- 其余域按 JD 从 [速记索引](/interview/review/00-overview#_9-篇速记册) 自选；偏基础岗可加 [Web 与计算机基础速记](/interview/review/sheets/01-web-fundamentals)
- 卡点回链入口：[JS 运行时与异步](/interview/review/topics/01-js-runtime)、[Vue3 响应式与渲染](/interview/review/topics/05-vue-reactivity)（只扫标题，不新开专题通讲）

#### 必做输出

- 在笔记写下「加重域 / 够用域 / 可跳过」三列（对照 JD）
- 遮稿口述加重域各 5 分钟：至少覆盖 [02 框架与数据](/interview/review/sheets/02-framework-data)、[03 工程与质量](/interview/review/sheets/03-engineering-quality)
- [09 领导力](/interview/review/sheets/09-leadership) 结论卡快过一遍，标出明天故事要用的 2 个钩子
- 卡点清单 ≥ 3 条：写「域 + 结论卡序号 / 追问句 + 回链题库模块」，不写「再看一遍」

#### 验收标准

加重域各能口述核心结论；卡点清单不少于 3 条。

---

### D2 — 主故事与模拟

任务 ID：`r3-d2-story-mock`

#### 学习目标

- 产出可上场的 5 分钟 STAR + 90 秒电梯版
- 完成至少 1 场模拟彩排（脚本任选一场）
- 准备失败与取舍两个追问分支

#### 材料

- [故事模板](/interview/stories/template)
- [故事示例](/interview/stories/examples)（对照结构，不背他人数字）
- [模拟脚本](/interview/mocks/scripts)（推荐按岗位选 [脚本一](/interview/mocks/scripts#脚本一-业务型中小厂-可抽查-java-联调) / [脚本三 Lead](/interview/mocks/scripts#脚本三-lead-面-分工、质量、技术选型) / [脚本十 行为](/interview/mocks/scripts#脚本十-项目答辩与行为面试-60-分钟)）
- [评分表](/interview/mocks/scorecard)
- [Lead、行为与项目答辩专题](/interview/review/topics/12-lead-behavioral)
- [领导力与求职速记](/interview/review/sheets/09-leadership)

#### 必做输出

- 按模板写满主故事：5 分钟 STAR + 90 秒电梯版；录音一遍，第二遍只看提纲
- 写下失败分支、取舍分支各 90 秒提纲，与简历数字对齐
- 完成 **至少 1 场** 完整模拟（无搭档用 [单人自测版](/interview/mocks/scripts#单人自测版-无搭档时)）；结束后用评分表记下 Top 3 卡点
- 从 [12 Lead / 行为专题](/interview/review/topics/12-lead-behavioral) 追问树走完一层，卡点回链题库 [22 项目答辩与行为](/interview/questions/22-project-behavioral)

#### 验收标准

主故事可脱稿；模拟后写下 3 个最高频卡点。

---

### D3 — 终检与反问

任务 ID：`r3-d3-final`

#### 学习目标

- 只回炉 D1 / D2 卡点，不新开战线
- 终检反问清单与简历证据一一对应
- 保持睡眠与上场节奏，避免通宵背题

#### 材料

- [反问清单](/interview/mocks/reverse-questions)
- [评分表](/interview/mocks/scorecard)
- D1 / D2 卡点对应的速记 / 专题（见 [复习总览](/interview/review/00-overview)）
- 按卡点回炉示例：[框架与数据速记](/interview/review/sheets/02-framework-data)、[工程与质量速记](/interview/review/sheets/03-engineering-quality)、[Vue3 响应式与渲染](/interview/review/topics/05-vue-reactivity)

#### 必做输出

- 把 D1 + D2 卡点合并为「上场 Top 5」，每条遮稿口述一遍并勾选通过 / 仍卡
- 仍卡的条目只回对应速记结论卡或专题验收清单勾选项，禁止新开整本专题
- 从 [反问清单](/interview/mocks/reverse-questions) 勾选 3～5 条上场版，并写清想听到的信息
- 终检：主故事电梯版再讲 1 遍；确认睡眠计划，不做通宵刷题

#### 验收标准

卡点各口述一遍通过；反问清单已勾选上场版。
