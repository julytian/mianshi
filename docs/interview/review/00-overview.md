# 复习总览

面试前临场回炉入口。长期备战走 [60 天完整主线](/interview/plans/60-day)；临场压缩走本模块；深挖追问回 [题库](/interview/questions/01-js-ts)。

---

## 三层分工

| 层 | 职责 | 不做什么 |
| -- | ---- | -------- |
| [学习路线](/interview/plans/60-day) | 长期能力建设（7 / 14 / 30 / 60 天） | 不负责面试前压缩回炉 |
| [题库](/interview/questions/01-js-ts) | 版本事实、边界、主答案与追问答案的唯一真源 | 不改成速记文风 |
| 复习模块（本页） | 完整可讲的浓缩讲义 + 临场日程 | 不发明与题库冲突的新口径 |

**长期备战走 60 天，临场走复习模块。** 两条线互不替代：60 天建能力，复习模块做回炉调度。

---

## 真源规则

1. 版本基线、API 语义、安全边界、平台差异以对应题库为准。
2. 复习层只允许浓缩、重组、补口述脚手架与案例坑位。
3. 发现冲突时优先修正复习文；仅当题库确有错误时才改题库，并单独提交说明。

禁止把复习页当成第二套互相打架的「标准答案」。

---

## 何时用 3 / 7 / 14 天

| 计划 | 适合场景 | 入口 |
| ---- | -------- | ---- |
| [面试前 3 天](/interview/review/plans/3-day) | 已约面，只扫速记 + 主故事 + 1 场模拟 | 最短临场 |
| [面试前 7 天](/interview/review/plans/7-day) | 回炉薄弱域 + 2 个专题 + 1～2 场模拟 | 一周窗口 |
| [面试前 14 天](/interview/review/plans/14-day) | 九域速记扫完 + 高频专题各过一遍 + 终场模拟 | 两周回炉 |

共同规则：每天 90～150 分钟；只调度速记、专题、模拟、故事 / 简历；完成标准是可口述并记录卡点。任务 ID 使用 `r3-` / `r7-` / `r14-` 前缀，不复用 60 天计划 ID。

这三档是**复习回炉计划**，与学习路线里的 [7 天压缩版](/interview/plans/7-day)、[14 天冲刺版](/interview/plans/14-day) 不同：后者仍属长期 / 压缩学习主线，前者专供面试前临场。

---

## 与 60 天路线的关系

- **先 60 天、再复习：** 有充足窗口时，默认走 [60 天完整主线](/interview/plans/60-day) 建完整能力地图与项目证据；临近面试再切本模块回炉。
- **时间不够：** 可直接选 3 / 7 / 14 天复习计划，但不要指望复习层替代题库深挖与长期练习。
- **卡点回流：** 复习口述卡住时，回到对应题库 Q/D 与追问链，再回速记 / 专题重讲。

## 建议用法

1. 对照 [总览与侧重点矩阵](/interview/00-overview) 标出加重域与薄弱域。
2. 按剩余天数进入对应回炉计划。
3. 每天先速记 / 专题口述，再连故事或模拟；卡点记下来回题库。
4. 面试前 24 小时优先领导力与求职速记 + 主故事 + 反问清单。
