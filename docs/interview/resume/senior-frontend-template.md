## 事实母版 / 面试证据台账（可选，不随简历投递）

为每条强结论保存以下字段：

```text
对应经历 / 项目：[名称]
简历结论：[投递版中的 1～2 行]
详细背景、难点、决策、行动、结果、复盘：[完整事实]
数据来源与统计口径：[平台、基线、时间窗、样本范围]
披露级别：[可公开 / 经公司制度及有权主体明确授权、仅向指定招聘方披露 / 不可对外]
授权依据：[公司制度条款 / 有权主体书面授权；第二级必填]
授权范围：[允许披露的数据、粒度和用途；第二级必填]
指定披露对象：[招聘公司 / 招聘方角色；第二级必填]
授权有效期：[起止日期或有效条件；第二级必填]
脱敏方式：[区间 / 比例 / 匿名化 / 删除]
是否仅供本人复盘：[是 / 否]
证明材料线索：[默认只记内部系统名称、工单号 / 检索线索]
```

可验证不等于允许披露。普通数据负责人、平台管理员或项目成员不当然具备对外授权权力；第二级必须符合公司制度并由有权主体明确授权。未经明确允许，不得下载、截图或转存公司材料到个人设备；默认只记录内部系统名称、工单号或检索线索。离职后仍须遵守保密义务和授权限制。
