# 资深前端完整面试路线与题库分类设计

## 1. 设计目标

现有题库已覆盖 Vue3、工程化、多端、微前端、架构、全栈和 AI，但通用 Web 能力仍分散在其他模块中，缺少以下独立能力域：

- HTML、CSS 与可访问性；
- 浏览器原理与 Web API；
- 网络协议与 Web 安全；
- 性能与用户体验；
- 测试与质量保障；
- Hybrid App；
- 项目答辩与行为面试；
- MySQL 与 Prisma。

本次重构目标：

1. 建立适用于通用资深前端岗位、同时突出 Vue3 与多端经验的完整能力地图。
2. 将零散知识重新归入职责清晰的题库模块。
3. 把题库扩展到 22 个模块、精确 550 题。
4. 新增 60 天完整复习主线，保留 7 / 14 / 30 天压缩路线。
5. 所有新增题目同时提供主答案和追问答案。
6. 为现有题库中的全部追问补充标准参考答案。
7. 将项目答辩、行为面试、简历、模拟和反问纳入正式训练阶段。

## 2. 岗位定位

主定位为「通用资深前端核心 + Vue3 / 多端 / 全栈专项」。

覆盖岗位：

- Senior Frontend / 资深前端工程师；
- Vue3 资深前端工程师；
- 前端 Tech Lead / 技术负责人；
- 全栈偏前工程师；
- AI 产品与创业团队前端负责人。

默认叙事：

- 前端基础和 Web 平台能力是共同底座；
- Vue3、Ant Design Vue、Vant、uni-app、微信小程序和 Hybrid App 是业务专项；
- Java、NestJS、MySQL、Prisma 与 AI 编程体现全链路交付能力；
- 架构、系统设计、领导力和行为面试用于证明资深判断力。

## 5. 新增题库边界

### 5.1 HTML / CSS / 可访问性

覆盖：

- 语义化 HTML、表单、图片和媒体；
- CSS 选择器、层叠、继承、BFC、格式化上下文；
- Flex、Grid、定位、层叠上下文和包含块；
- 响应式、容器查询、逻辑属性、安全区；
- CSS 性能、`contain`、`content-visibility`；
- WCAG、键盘、焦点、ARIA、屏幕阅读器；
- 复杂后台和移动端可访问性。

边界：浏览器渲染流水线归入「浏览器与 Web API」；性能指标归入「性能与用户体验」。

### 5.2 浏览器与 Web API

覆盖：

- 导航、解析、样式、布局、绘制与合成；
- Event Loop、任务、微任务和渲染机会；
- DOM、事件传播、Observer API；
- Storage、IndexedDB、Cookie 和缓存边界；
- Worker、Service Worker、BroadcastChannel；
- Page Lifecycle、BFCache、History、Clipboard；
- Web Components、Shadow DOM、PWA；
- 内存泄漏、性能分析和兼容性。

边界：HTTP、TLS、CORS、CSP 归入网络安全；框架调度归入 Vue3。

### 5.3 网络与 Web 安全

覆盖：

- DNS、TCP、TLS、HTTP/1.1、HTTP/2、HTTP/3；
- CDN、代理、缓存、协商缓存和内容编码；
- Cookie、Session、Token、OAuth / OIDC + PKCE；
- CORS、CSRF、XSS、CSP、Trusted Types；
- 点击劫持、开放重定向、SSRF 的前端协作边界；
- SRI、供应链、第三方脚本和上传安全；
- WebSocket、SSE、重试、幂等和弱网；
- 安全响应头、日志脱敏和安全事件处置。

边界：业务权限模型归入前端架构；依赖审计流水线归入工程化。

### 5.4 Hybrid App

覆盖：

- WebView + Native Shell + Web 资源架构；
- JSBridge 协议、版本、序列化、回调、超时和取消；
- Android / iOS WebView 差异；
- Cookie、登录态、SSO、网络代理和证书；
- 相机、定位、文件、上传下载和权限；
- 前后台生命周期、返回栈、进程回收和状态恢复；
- 白屏、启动耗时、WebView 池、预加载和缓存；
- 域名白名单、导航拦截、参数校验和不可信内容；
- 原生插件、版本兼容、降级和可观测性；
- uni-app App、Capacitor、Cordova 的适用边界；
- 签名、应用商店、热更新合规和回滚；
- Hybrid、PWA、React Native、Flutter、原生方案选型。

边界：普通移动浏览器问题归入 Vant H5；微信小程序运行机制归入 uni-app / 小程序。

### 5.5 性能与用户体验

覆盖：

- Core Web Vitals、用户体验 SLI / SLO；
- RUM、实验室数据和性能预算；
- 加载链路、资源优先级、预加载和缓存；
- Bundle、Chunk、Tree-shaking 和第三方脚本；
- 图片、字体、CSS、JavaScript 执行优化；
- 长任务、INP、布局抖动和内存；
- Vue 大列表、大表单和响应式降级；
- 性能回归、告警、灰度和业务指标关联。

边界：构建器配置归入工程化；浏览器渲染原理归入浏览器模块。

### 5.6 测试与质量保障

覆盖：

- 测试金字塔和风险分层；
- Vitest、Vue Test Utils、Mock 和 Fake；
- 组件、Composable、Pinia、Router 测试；
- Playwright E2E、视觉回归和可访问性测试；
- API 契约、Schema、集成测试和测试数据库；
- 属性测试、变异测试和故障注入；
- Flaky Test、测试隔离、并行和数据清理；
- 覆盖率边界、质量门禁和发布信心。

边界：CI 任务图归入工程化；手写算法测试归入手写题。

### 5.7 项目答辩与行为面试

覆盖：

- 自我介绍和岗位定位；
- 主项目 3 / 5 / 10 分钟版本；
- STAR-L、失败案例和复盘；
- 技术取舍、指标口径和个人贡献；
- 冲突、推动、反馈、培养和跨团队协作；
- 事故、排期、需求变化和优先级；
- 产品判断、业务理解和客户价值；
- 离职原因、职业规划和岗位匹配；
- 诚信、保密和无法回答时的处理；
- 反问、薪酬沟通和面试收尾边界。

边界：组织机制和 Lead 方法论归入架构 / Lead；本模块聚焦面试表达和证据。

## 6. 题型与答案标准

### Q 题

- 高频基础、场景判断和短链路排障；
- 主答案可在 1～2 分钟内口述；
- 包含考察点、参考答案、追问和追问答案。

### D 题

- 原理、故障、架构取舍和演进；
- 主答案包含基础结论、原理深挖、工程场景、反例 / 踩坑和资深回答模板；
- 追问链逐项提供约 100～200 字参考答案。

### 项目与行为题

- 使用 STAR-L：背景、任务、行动、结果、复盘；
- 结果必须说明证据来源、口径和时间窗；
- 区分个人完成、协作推动和团队机制；
- 不编造经历、指标或公司内部材料。

## 11. 风险与控制

### 内容规模

550 道主问题及其追问答案会明显增加构建体积和搜索索引。每个模块独立审查，并在最终构建中观察 chunk、页面生成时间和线上加载。

### 模块重叠

通过边界说明控制重复：

- 浏览器原理不重复 Vue 调度；
- 网络安全不重复业务权限；
- 性能模块不重复构建器配置；
- Hybrid App 不重复普通 H5 和小程序；
- 项目行为题不重复 Lead 管理方法论。

### 技术事实漂移

Vite、Vue、NestJS、Prisma、Cursor、Hybrid 容器和小程序能力均存在版本差异。实施时优先核对官方资料，并标注版本敏感内容。

### 复习负担

550 题不要求顺序通刷。60 天路线按岗位权重选择 D 题，7 / 14 / 30 天路线用于不同时间压力下裁剪。
