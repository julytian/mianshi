# 微前端面试题库

## 适合岗位 / 定位

面向 **3 年+ 前端**、**全栈偏前** 与 **前端 Lead** 候选人，默认上下文为 Vue 3 管理后台与多团队协作场景。本模块聚焦 **运行时应用编排、模块远程加载与隔离治理**，与 [前端架构](/interview/questions/14-frontend-architecture)（系统组织与演进）和 [前端系统设计](/interview/questions/11-frontend-system-design)（具体案例设计）形成互补阅读路径。

## 使用方法

先盖住答案，按 **适用边界 → 方案对比 → 工程治理 → 故障降级** 自己口述 2～3 分钟，再对照后续题目补洞。追问用来模拟面试官加压；踩坑是实战里最容易翻车的点。中英文术语之间请习惯留空格，口述时也建议如此。
