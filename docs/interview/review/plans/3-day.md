# 面试前 3 天

> **适合场景：** 已约面，只扫速记 + 主故事 + 1 场模拟。
>
> **每日时长：** 90～150 分钟。
>
> **完成标准：** 当天主题可遮稿口述；卡点写入笔记；不新开题库通刷战线。
>
> **任务 ID 前缀：** `r3-d{n}-{slug}`（禁止复用 60 天计划 ID）。

长期能力建设仍以 [60 天完整主线](/interview/plans/60-day) 为准；本页是临场回炉，入口见 [复习总览](/interview/review/00-overview)。

---

## 阶段总览

| 天数 | 重心 | 任务 ID |

| D2 | 主故事压实 + 模拟彩排 | `r3-d2-story-mock` |

---

### D1 — 九域速记快扫

任务 ID：`r3-d1-sheet-scan`

#### 学习目标

- 按 JD 标出加重域，速记册只扫结论卡与反例 / 红线
- 建立遮稿口述节奏，单域控制在可上场的 5 分钟量级
- 记下卡点题号，不展开通读题库

#### 材料

- [复习总览](/interview/review/00-overview)
- [框架与数据速记](/interview/review/sheets/02-framework-data)
- [工程与质量速记](/interview/review/sheets/03-engineering-quality)
- [领导力与求职速记](/interview/review/sheets/09-leadership)
- 其余域按 JD 从 [速记索引](/interview/review/00-overview#9-篇速记册) 自选

#### 必做输出

本页正文在后续批次写满（具体口述任务与题号在 Task 5 填入）。

#### 验收标准

加重域各能口述核心结论；卡点清单不少于 3 条。

---

### D2 — 主故事与模拟

任务 ID：`r3-d2-story-mock`

#### 学习目标

- 产出可上场的 5 分钟 STAR + 90 秒电梯版
- 完成至少 1 场模拟彩排（脚本任选一场）
- 准备失败与取舍两个追问分支

#### 材料

- [故事模板](/interview/stories/template)
- [模拟脚本](/interview/mocks/scripts)
- [Lead、行为与项目答辩专题](/interview/review/topics/12-lead-behavioral)
- [领导力与求职速记](/interview/review/sheets/09-leadership)

#### 必做输出

本页正文在后续批次写满（具体口述任务与题号在 Task 5 填入）。

#### 验收标准

主故事可脱稿；模拟后写下 3 个最高频卡点。

---

### D3 — 终检与反问

任务 ID：`r3-d3-final`

#### 学习目标

- 只回炉 D1 / D2 卡点，不新开战线
- 终检反问清单与简历证据一一对应
- 保持睡眠与上场节奏，避免通宵背题

#### 材料

- [反问清单](/interview/mocks/reverse-questions)
- [评分表](/interview/mocks/scorecard)
- D1 / D2 卡点对应的速记 / 专题（见 [复习总览](/interview/review/00-overview)）

#### 必做输出

本页正文在后续批次写满（具体口述任务与题号在 Task 5 填入）。

#### 验收标准

卡点各口述一遍通过；反问清单已勾选上场版。
