# NestJS 面试题库

## 适合岗位 / 定位

面向 **全栈偏前**、**Node.js 后端** 与 **Vue + BFF 联调** 场景，覆盖 NestJS 从日常 CRUD 到生产工程与高级架构的完整链路。表达保持 Node.js / TypeScript 语境，不机械套用 Spring 概念；与 [Java 全栈偏前](/interview/questions/07-java-fullstack) 形成对照，便于按岗位切换复习重点。

## 使用方法

先盖住答案，按 **机制 → 请求链路 → 数据与安全 → 生产运维** 自己口述 2～3 分钟，再对照后续题目补洞。追问用来模拟面试官加压；踩坑是实战里最容易翻车的点。中英文术语之间请习惯留空格，口述时也建议如此。

## 题量目标

| 类型 | 数量 |
| ---- | ---- |
| 普通题 | 20–23 道 |
| 深层题 | 15–18 道 |
| 合计 | 35–38 道 |

## 后续章节目录

1. **核心机制** — Module、Controller、Provider、依赖注入与模块可见性
2. **请求链路** — Middleware、Pipe、Guard、Interceptor、Exception Filter 执行顺序与职责
3. **数据与鉴权** — DTO / Validation、TypeORM / Prisma、JWT、RBAC / ABAC 与 Vue 联调契约
4. **生产工程** — 配置、日志、测试、部署、限流、幂等与优雅停机
5. **高级架构** — 微服务 Transport、事件驱动、CQRS、DDD 与模块化单体取舍
6. **深层题** — Decorator / Metadata、容器扫描、动态模块、并发安全与源码机制
