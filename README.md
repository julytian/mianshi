# 前端面试作战手册

面向 **Vue3 + Java 全栈偏前** 与 **AI / vibe coding** 协作场景的本地面试知识库，基于 [VitePress](https://vitepress.dev/) 构建。

## 快速开始

```bash
pnpm install
pnpm docs:dev
```

构建静态站点：

```bash
pnpm docs:build
pnpm docs:preview
```

## 从哪里读起

建议先打开站点内的 **[总览与侧重点矩阵](/interview/00-overview)**（开发时访问 `http://localhost:5173/interview/00-overview`），根据目标岗位调整复习权重，再进入冲刺计划与题库。

## 技术栈

- VitePress 1.x + Vue 3
- 本地全文搜索（中文导航与侧栏）
