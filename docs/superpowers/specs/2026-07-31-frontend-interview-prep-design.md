> 日期：2026-07-31
> 状态：待用户审阅（已根据反馈补充 Java 后端；自检通过）
> 受众：10 年经验，Vue3 + TypeScript，uni-app / 微信小程序，Ant Design Vue 管理后台，Vant H5；AI vibe coding 时以后端 **Java（Spring Boot）** 为主

## 1. 目标与成功标准

### 1.1 目标岗位（同时覆盖）

- **A. 高级 / 资深前端**：业务落地 + Vue 技术栈深度
- **B. 前端 Tech Lead / 技术负责人**：带人 + 架构 + 工程化决策
- **C. 全栈偏前**：能用 Java Spring Boot 独立或与 AI 协作完成接口 / 简单业务后端，前后端联调与接口设计能聊透，但仍以前端为主岗叙述

### 1.2 投递公司类型

混合投递，并按类型切换侧重点；单独加强创业 / AI 产品方向：

- 大厂 / 互联网中大厂
- 业务型中小公司 / ToB SaaS
- 外包 / 交付型
- 创业公司 / AI 相关产品

### 1.3 成功标准

- 能按公司类型快速切换复习重点，而不是盲目背整库
- 所有题目均有参考答案，可先想后对
- 有可执行的 14 天主计划，以及 7 天压缩版、30 天加练版
- 本地 VitePress 站点可浏览、搜索、按天勾选进度
- 能稳定讲清项目故事（管理后台 + 跨端 + AI 全栈交付），并应对 Lead / AI 协作 / Java 联调追问
- 能把「前端主栈 + Java vibe coding」讲成差异化优势，而不是抢后端岗的八股比赛

## 3. 候选人技术画像（内容撰写基准）

### 3.1 前端主栈

- Vue3 + TypeScript
- Ant Design Vue（管理后台）
- Vant（H5）
- uni-app / 微信小程序
- Vite、常规前端工程化与性能治理

### 3.2 AI vibe coding 后端栈（Java）

默认按 **E：单体为主，微服务点到为止**：

- **主路径：** Spring Boot + MyBatis / MyBatis-Plus + MySQL
- **按需中间件：** Redis、消息队列（如 RabbitMQ / RocketMQ，够用即可）
- **认证授权：** 常见如 JWT / Sa-Token 等（以能讲清登录态与前后端约定为准）
- **微服务：** 偶尔接触（Gateway、Nacos、Feign 等）——题库只覆盖「知道是什么、什么时候拆、前端如何对接」，不深挖中间件八股与源码

### 3.3 叙事边界（重要）

- 面试主身份仍是 **前端 / 前端 Lead**
- Java 部分定位为：**能独立扛简单后端、能设计接口、能联调排障、能用 AI 加速交付**
- 明确不做：JVM 调优深挖、分布式事务论文级讲解、与专职后端拼中间件细节

Node.js 仅保留极少量「前端工程脚本 / BFF 认知」内容，**不再作为全栈主后端题库**。

### 5.1 Java 模块内容边界

题库覆盖（前端视角 + 能落地）：

- Spring Boot 项目结构、分层（Controller / Service / Mapper）
- RESTful 接口设计、统一响应、错误码、分页约定
- MyBatis-Plus 常见 CRUD、条件构造、与前端表格/筛选联动
- 登录鉴权（JWT 等）与前端 Token 存储、刷新、权限码对齐
- Redis 缓存使用场景（会话、热点读、防抖提交）与缓存一致性的口语级解释
- 文件上传、导出 Excel 等后台常见联调
- 事务边界（什么放 Service、前端如何避免重复提交）
- 微服务「点到为止」：为何拆、网关对前端的影响、环境与配置意识
- 用 AI 生成 / 修改 Java 代码时的审查清单（SQL 注入、越权、N+1、空洞异常处理）

不覆盖：JVM 调优专题、复杂分布式事务、中间件源码、海量 Java 手写算法。

### 5.2 统一题型模板（全部题目必须遵守）

每道题包含：

1. **题目**
2. **考察点**
3. **参考答案**（必须有；禁止只留「自行组织」）
4. **追问链**（Vue3 / 工程化 / AI / Java 高频题必有；其余按需）
5. **踩坑提醒**（按需）

站点呈现：题目默认展开，**参考答案默认折叠**，支持「先想后看」。

### 5.3 侧重点矩阵

| 公司类型      | 加重                                           | 可弱化                              |
| ------------- | ---------------------------------------------- | ----------------------------------- |
| 大厂 / 中大厂 | JS/TS、Vue 原理、手写、性能、系统设计          | 业务组件细节；Java 只保留接口与协作 |
| 业务型 / ToB  | 后台架构、工程化、稳定性、AntDV、Java 联调     | 算法深度、微服务八股                |
| 外包 / 交付   | 多端、uni-app、交付节奏、踩坑                  | 过深原理                            |
| 创业 / AI     | AI 协作、Vue+Java 快速闭环、产品感             | 八股堆叠                            |
| Lead 面       | 带人、技术决策、质量门禁、排期取舍、前后端分工 | 单纯背题                            |

## 6. 冲刺计划

### 6.1 14 天主线（每天约 2–3 小时）

| 阶段       | 天数    | 重心                                           |
| ---------- | ------- | ---------------------------------------------- |
| 底座夯实   | D1–D3   | JS/TS + Vue3 核心 + 主项目故事打磨             |
| 业务与多端 | D4–D6   | AntDV + Vant H5 + uni-app / 小程序             |
| 资深分水岭 | D7–D9   | 工程化 + 性能 + **Java 全栈偏前**              |
| Lead 与 AI | D10–D11 | 架构决策、带人、**AI + Java vibe coding 叙事** |
| 模拟与收敛 | D12–D14 | 按公司类型模拟 ×2 + 弱项回炉 + 反问清单        |

每日结构：做题自测（对答案）→ 口述 1 个项目故事 → 记录卡壳点。

### 6.2 7 天压缩版

砍掉手写 / 系统设计深挖；保留 Vue3 + 工程化 + 主项目故事 + **AI+Java 叙事** + 1 场模拟。

### 6.3 30 天加练版

在 14 天基础上增加：手写隔日练、系统设计周更、每周 1 场完整模拟、按投递公司切换矩阵；可选加练「一个最小 Spring Boot CRUD + Vue 联调」口述闭环。

### 6.4 计划页交互

- 每日 checklist
- 勾选进度写入 `localStorage`（无后端、无账号）
- 不要求跨设备同步

## 7. 项目故事与模拟面试

### 7.1 故事线

- 模板：STAR-L（Situation / Task / Action / Result / Learning）
- 至少 3 条主线：
  1. 管理后台（Ant Design Vue）：复杂表格、权限、性能、组件沉淀
  2. 跨端（uni-app / 小程序 / H5）：多端差异、包体积、登录态、发布链路
  3. **AI + Java 全栈交付**：用 AI 辅助 Spring Boot 接口 + Vue 页面快速闭环，强调审查、联调、边界与交付质量
- 每条准备：30 秒 / 2 分钟 / 5 分钟版本 + 至少 3 个预埋追问与参考答法

### 7.2 模拟面试

三套脚本：

1. 业务型中小厂（可抽查 Java 联调）
2. 创业 / AI 产品（加重 vibe coding + Java）
3. Lead 面（分工、质量、技术选型含是否上 Java 单体）

每套流程：自我介绍 → 项目深挖 → 模块题抽查 → 系统设计或协作题 → 候选人反问。

附：评分表（技术深度 / 表达结构 / 决策取舍 / AI 协作成熟度 / 前后端闭环能力）+ 反问清单。

- **首页**：一句话定位（含 Java vibe coding 差异化）+ 四大入口

- **答案折叠**：默认收起参考答案

### 8.1 明确不做

- 账号系统、后端、云同步（指本学习站本身）
- 算法题海（仅前端常考手写）
- React 深挖
- Java 后端八股竞赛（JVM / 分布式深挖）
- 在线部署作为必选项（首期只保证本地）
