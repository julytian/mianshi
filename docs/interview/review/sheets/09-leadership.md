# 领导力与求职速记

> **真源：** [08 架构 / Lead](/interview/questions/08-architecture-lead)、[22 项目与行为](/interview/questions/22-project-behavioral) 为唯一真源；冲突时以题库为准。简历与模拟题仅作故事素材，不覆盖题库口径。
>
> **用法：** 面试前遮住口述稿先自讲，再对结论卡与追问速答。证据坑位请填入你自己的项目指标，勿背他人数字。

## 一句话定位

本域讲清「Lead 的选型 / 债 / 门禁 / 复盘节奏 + 可核验的项目答辩与行为题」。资深面试要的是**决策质量与影响他人的证据**，不是管理黑话。你应能在五分钟内把一条主项目 STAR-L、一次取舍、一次失败复盘与反问清单讲顺。

## 核心结论卡

1. **结论：** 技术选型用约束、选项、风险、验证与退出条件拍板，不跟风最火。  
   **边界：** 写 ADR：上下文、选项、取舍、后果；预设停止线。  
   **证据坑位：** 〔填〕一次选型会纪要或 ADR 链接。

2. **结论：** 技术债分级：利息（交付 / 事故 / 人效）× 本金；预算绑可验收结果，不争抽象「百分之二十重构」。  
   **边界：** 无 owner 的债等于不存在。  
   **证据坑位：** 〔填〕债清单 Top3 与本期偿还结果。

3. **结论：** 估期给范围、假设、风险缓冲；必砍时按价值 / 风险 / 依赖透明化，守住安全底线。  
   **边界：** 单点英雄式承诺不可持续。  
   **证据坑位：** 〔填〕一次砍范围仍交付的对照。

4. **结论：** Code Review 挡正确性、安全、可回滚与契约破坏；风格争议工具化，不做警察。  
   **边界：** 必须改与建议改要分标。  
   **证据坑位：** 〔填〕一条「挡住上线」的评论样例（脱敏）。

5. **结论：** 质量门禁红灯：安全、数据损坏、无可观测发布；黄灯例外限时补偿。  
   **边界：** 重试变绿不是门禁。  
   **证据坑位：** 〔填〕门禁策略页与一次例外单。

6. **结论：** 带新人 30 天：环境、小闭环、结对、可回滚任务；生产权限渐进。  
   **边界：** 只扔文档不等于 onboarding。  
   **证据坑位：** 〔填〕新人首月产出与事故为零的支撑。

7. **结论：** 多端并行按能力与风险分人，设集成节奏与唯一优先级入口，避免人人全栈救火。  
   **边界：** 共享核心变更要有窗口。  
   **证据坑位：** 〔填〕某迭代人力分配与延期归因。

8. **结论：** 事故指挥官控节奏与决策，不埋头只改一行；先止损再恢复再根因。  
   **边界：** 复盘无责文化对事不对人，但要有行动项 owner。  
   **证据坑位：** 〔填〕一次 postmortem 行动项完成率。

9. **结论：** 接口契约冲突以用户影响与兼容成本裁决，书面化；BFF / 前端不强行「谁官大谁说了算」。  
   **边界：** 口头约定不算契约。  
   **证据坑位：** 〔填〕一次契约争议的结论记录。

10. **结论：** 推进设计体系：先痛点试点、证明收益，再治理；无职权靠证据与共同收益。  
    **边界：** 大爆炸换组件库常失败。  
    **证据坑位：** 〔填〕试点页面数与接入成本下降证据。

11. **结论：** 与产品博弈：翻译成价值、成本、风险、学习速度；决策权在有授权 owner。  
    **边界：** Tech Lead 不假装替代产品经理。  
    **证据坑位：** 〔填〕一次需求降级仍保目标的案例。

12. **结论：** 招聘按级别必须项 / 加分项 / 不可接受项与评分锚点；校准面试官。  
    **边界：** 不复制「和我很像」画像。  
    **证据坑位：** 〔填〕职级标准一页纸与一次校准会。

13. **结论：** 项目答辩准备 3 / 5 / 10 分钟三版：共享 STAR-L 主线，加长时加取舍与治理证据。  
    **边界：** 无法核验的精确数字差过有边界的定性证据。  
    **证据坑位：** 〔填〕主项目三版口述稿与指标口径说明。

14. **结论：** 失败 / 事故题讲责任、证据、系统改进；无经历就诚实说，讲最接近的高风险或演练。  
    **边界：** 不编造故障，不泄密。  
    **证据坑位：** 〔填〕一次真实复盘的改进项。

15. **结论：** 无职权影响：事实、对方收益、低摩擦试点、清晰决策机制。  
    **边界：** 声音大不等于对齐。  
    **证据坑位：** 〔填〕一次跨团队推动落地的时间线。

16. **结论：** 优先级把价值、时效、风险、容量、不做成本透明化，最终由业务授权人取舍，技术守安全线。  
    **边界：** 多项目抢人时拒绝私下加塞。  
    **证据坑位：** 〔填〕一次排期冲突的决策记录。

17. **结论：** 职业叙事：离开原因专业短、面向未来；规划连业务问题与能力，不背空口号。  
    **边界：** 反问展示判断力：团队节奏、成功标准、技术债现实。  
    **证据坑位：** 〔填〕个性化反问清单 5 条。

18. **结论：** 绩效与反馈谈行为与影响；无人事权不暗示能决定去留。  
    **边界：** 尖锐反馈要可观察下一步。  
    **证据坑位：** 〔填〕一次反馈后的行为变化观察。

## 高频追问速答

1. **选型你怎么证明不是跟风？**  
   先列约束与成功指标，再给不少于两个可执行选项，比较风险、成本、团队技能与退出条件，用小 PoC 或试点验证关键不确定点，最后写入 ADR。若后来证伪，按预设停止线缩小或退出，而不是沉没成本硬扛。面试官要听的是决策过程与可回退性，不是最终商标念得多新。

2. **技术债预算怎么跟业务要？**  
   把债翻译成利息：交付变慢、事故概率、招聘与 onboarding 成本，并给出可验收偿还包，而不是抽象百分比时间。用小结果证明偿还能降低后续需求成本，再扩大预算。多团队共享时当投资组合管理，有 owner、有截止、有不做的后果。没有指标与故事的「重构申请」很难过。

3. **线上事故你当指挥官怎么做？**  
   建立通讯节奏与唯一决策通道，先控制影响面（开关、回滚、限流），再恢复关键路径，最后安排根因与复盘。指挥官不兼任唯一排查人。信息要时间戳与事实，不做指责。恢复后 24～72 小时内出行动项：检测、门禁、演练。前端 Lead 要能说清自己在止损中的具体动作，而不是只说「大家很拼」。

4. **主项目 3 分钟怎么讲？**  
   用 STAR-L：背景与为何重要、你的责任边界、关键行动与取舍、可核验结果、复盘与若重来。数字要有口径、窗口与归因边界；没有漂亮数字就用质量与风险证据。避免团队大词淹没个人贡献，也避免把集体成果说成一人完成。准备好两个追问入口：架构取舍与一次翻车。

5. **跨团队撕逼你怎么收敛？**  
   把立场改写成共同目标、约束与可比较选项，补齐数据与试点，明确决策权与升级路径。无职权时用对方收益与低摩擦试点推动，而不是会议耗尽。目标是可接受风险下推进，不是让所有人喜欢你的方案。留下书面结论，避免下周重吵。安全与合规底线不进入「折中掉」。

6. **失败题没有重大事故怎么办？**  
   诚实说明没有造成重大损失的事故，再讲最接近的高风险事件、差点出事的缺陷或正式演练：当时信号、你的判断、系统上如何补检测与门禁。重点是学习与改进，不是戏剧性。编造事故一旦被追问细节会崩，且有诚信风险。保密信息用脱敏与边界说明处理。

7. **反问什么显得资深？**  
   问清岗位六到十二个月成功标准、团队交付节奏与质量现实、技术债与平台投入、跨团队协作方式、以及这次招聘要补的能力缺口。避免只问薪资班车。用反问验证你是否能创造价值，也展示你做决策的信息需求。最后可确认后续流程与你是否还需补充材料，收尾干净。

8. **为什么离开上家怎么答？**  
   短、专业、面向未来：业务阶段变化、能力成长边界、或方向匹配，不攻击前雇主与同事。准备一句与目标岗位的连接：你想解决的问题与对方阶段吻合。细节点到为止，把时间留给项目与能力证据。若被追问冲突，仍回到事实、你的行为与学习，不把面试变成吐槽大会。

## 反例 / 红线

- 无法核验的精确「提升百分之多少」却说不清口径。
- 编造事故、泄密、或把集体成果全部归自己。
- 无停止线的技术崇拜；CR 只刷风格。
- 无职权却暗示能决定他人去留或薪资。
- 反问只关心假期薪资，零业务与团队信息。
- 复盘只追责个人，无系统行动项。

## 5 分钟口述稿

「领导力我讲决策与节奏：选型有约束与 ADR，债务有利息与偿还包，门禁有红灯与限时例外，事故先止损再复盘。带人给小闭环，跨团队用目标与书面契约，推进平台靠试点证据。多项目抢排期时把价值与风险摊开，守住安全底线，拒绝私下加塞。

求职侧我准备三版项目口述，指标可核验，失败讲系统改进，冲突讲收敛机制，反问对准成功标准与债现实。离开原因短而专业。现场把个人贡献边界说清，不吞团队成果，也不编造事故。收口用一份 ADR、一次 postmortem 行动项和主项目 3 分钟稿，数字靠口径不靠吹。」
