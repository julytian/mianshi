# 前端架构面试题库

## 适合岗位 / 定位

面向 **5 年+ 前端**、**前端架构师** 与 **技术骨干**，回答「系统应该如何组织和演进」。重点是 **技术结构、质量属性与治理机制**；带人与排期决策见 [架构 / Lead](/interview/questions/08-architecture-lead)，端到端案例设计见 [前端系统设计](/interview/questions/11-frontend-system-design)。

## 使用方法

先盖住答案，按 **约束识别 → 分层与边界 → 质量属性 → 演进路径** 自己口述 2～3 分钟，再对照后续题目补洞。追问用来模拟面试官加压；踩坑是实战里最容易翻车的点。中英文术语之间请习惯留空格，口述时也建议如此。

## 题量目标

| 类型 | 数量 |
| ---- | ---- |
| 普通题 | 14–16 道 |
| 深层题 | 14–16 道 |
| 合计 | 28–30 道 |

## 后续章节目录

1. **架构基础** — 目标与约束、质量属性、分层与依赖方向
2. **模块与数据** — 领域拆分、状态与数据流、接口层、错误模型与权限模型
3. **工程与发布** — Monorepo、依赖治理、构建体系、发布体系与环境治理
4. **性能稳定性** — 性能预算、可观测性、安全边界与灾备降级
5. **演进治理** — 技术债识别、架构评审、决策记录与渐进式演进
6. **深层题** — 从业务约束推导架构、平台化取舍、多团队协作边界
